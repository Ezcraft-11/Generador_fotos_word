# Organizador de Fotos a Word

Herramienta para convertir imágenes y organizar automáticamente en un documento de Word con una caudricula 2x2 en orientación horizontal.

## Características

* Conviete archivos '.heic' a '.jpg' con ```Convertir_heic_a_jpg.py```
* Generación de un archivo Word independiente por cada 4 fotos

## Descarga rápida

### Para convertir .heic a .png
1. Ve a la sección **Releases** en la barra lateral derecha de este repositorio.
2. Descarga el archivo `.exe`.
3. Crea una carpeta llamada `mis_fotos` en la misma ubicación del ejecutable y guardatus fotos ahí.
4. Ejecuta el programa.

### Para Generar Word
1. Ve a la sección **Releases** en la barra lateral derecha de este repositorio.
2. Descarga el archivo `.exe`.
3. Crea una carpeta llamada `Fotos_JPG` en la misma ubicación del ejecutable y guardatus fotos ahí.
4. Ejecuta el programa.

## Uso con Python
1. Clona el repo
2. Instala las dependencias:
```bash
pip install -r requirements.txt
```
3. Ejecuta el script:
```bash
python main.py
```
